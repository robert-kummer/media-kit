# Typografie

| Rolle | Schrift | Schnitt |
|---|---|---|
| Headlines, UI, Wortmarke | **Geist** | 600 (SemiBold), Headlines mit `letter-spacing: -0.035em` bis `-0.045em` |
| Fließtext | **Geist** | 400 |
| Labels, Meta, Code | **Geist Mono** | 400–500, 12–14 px |

Beide Schriften: SIL Open Font License, von Vercel. Bezug über Google Fonts oder das npm-Paket `geist`.

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Geist:wght@300..800&family=Geist+Mono:wght@400;500;600&display=swap">
```

Die Wortmarke in `logo/wordmark/` und `logo/lockup/` ist in Pfade umgewandelt (Geist SemiBold, Tracking −0.02em) und braucht keine installierte Schrift.
